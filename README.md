# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

拼配配方先草案再生效：草案可改母叶清单，点生效后生成只读版本号，之后只能新建草案。交评必须挑选一个已生效版本号，否则拒交。顶栏可进配方版本专页；观察员只能看版本列表与生效正文。

这是制茶审评，不是菜谱，也不是饮食记录。

## 启动

```bash
cd projects/13-tea-blend-cupping
docker compose up --build
```

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 顶栏进「配方版本」，新建草案，挂两味母叶（如 春芽、秋芽），点生效得到版本 1。
3. 再新建草案改母叶，版本 1 正文不变。
4. 回审评记录交「春芽」批次并选版本 1，提交成功，新行出现在表头，页面不整页刷新；不选版本号会被拒交。
5. observer 登录后没有提交表单；能翻版本列表与生效正文，但没有新建草案和生效按钮。
